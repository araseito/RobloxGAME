### 3. 残っている仮置き

- **エリアの地形がない**。里山とダンジョンは、印がなければ平らな仮の足場（町から 700 stud 離れた場所）。Studio で作ったら `Workspace.Spawns` に `Spawn_satoyama` などの Part を、モンスターの出現点は `Workspace.MonsterSpawns` にモンスター ID の名前の Part を、隠し場所は `ExploreSpot_e02` を置けばそこに移る
- **モンスターの見た目は色つきの箱と球**。動きは地面の高さが一定の前提（起伏のある地形では浮く・埋まる）
- **数値はすべて仮**。特にモリポン 4 体の群れは強い（何もしないと約 11 秒で倒れた）。ダメージ・攻撃間隔・数は Config と MonsterDefs で調整する
- 合成はどこでもできる（場所の決まりが仕様になかったため）

### 4. 仕様と迷った点

- 「出会った」は、モンスターに狙われたとき・倒したときに付ける
- ボスの「ダメージを一定以上」は、最大 HP の 10% にした（`Config.Drops.BossContributionRatio`）
- 倒れて復活すると町に戻る（今いるエリアも町に戻る）
- 移動にクールダウン 2 秒を付けた（連打で行き来しないように）。PvE の戦闘中でも移動できる（逃げられる）
