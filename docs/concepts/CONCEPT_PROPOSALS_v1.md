# 新しい企画の候補 v1（2026-11-27）

Phase 0（パズルボックス）とは別に考えるための案。Phase 0 の仕様・コードには手を入れない。

## 前提にしたこと

**上位ゲームの要素**（`top-game-patterns` のメモより）
1. 集める → 拠点に置く → 放置で増える
2. 強化の効き目がすぐ見える（1 つの数値で行ける場所が広がる）
3. 時間で「また来る理由」（在庫の入れ替え、一斉リセット、週替わり）
4. 相手を待たない、ゆるい対人（盗む・奪う・落とさせる）
5. 珍しさの段階と、見せびらかし
6. スマホ前提、短い 1 周

**なろう系の定番**：追放からの成り上がり、ハズレスキルが実は最強、辺境でスローライフ・開拓、テイマー（従魔）、ダンジョン経営、生産職・料理、鑑定、ステータス画面。
※ 2026 年の流行を確かめられる公式の集計は見つからなかった。ハイファンタジーと異世界恋愛が中心という記事はある。Roblox の遊び手は若く、世界中にいるので、恋愛ものより「強くなる・集める・育てる」の方が合う。

**動画の助言**：1 本目は小さく作る。対戦が主役だと人が少ないうちは遊べない。最初の 2 分で何をするゲームか分かるようにする。

**守ること**：特定の作品の名前・キャラクター・設定は使わない。「定番の型」だけを借りる。

## 案 A：ハズレスキル覚醒屋

> 「ハズレ」と言われたスキルの玉を危ない迷宮から持ち帰り、自分の祠で覚醒させて最強の組み合わせを作る

| 項目 | 内容 |
| --- | --- |
| なろうの型 | ハズレスキルが実は最強、鑑定 |
| 1 周 | 迷宮でスキルの玉を拾う → 運んで帰る（途中で落とすことがある）→ 祠に置くと少しずつ覚醒し、放置で経験値が貯まる → 覚醒したスキルを付けて、もっと深い階へ |
| 上位ゲームの要素 | 1（祠で放置覚醒）、2（「脚力」で行ける階が増える）、3（迷宮の玉は 15 分ごとに一斉に入れ替わる）、4（運んでいる人を叩くと玉を落とす。拾った人のものになる）、5（覚醒の段階で玉の色が変わり、祠に並ぶ） |
| 1 人で遊べるか | ○ 迷宮の見張り（NPC）が邪魔をする |
| 今の資産で使えるもの | **付与と解除のしくみがそのまま「スキルを付ける」になる**。上限コスト、必殺技の種類の決まり方、InventoryService、DataService、戦闘 |
| 小さく作るなら | 迷宮 3 階、スキル 9 種、覚醒 3 段階、祠 1 つ |
| 危ないところ | 「叩いて落とさせる」で嫌な思いをする人が出る。町ではできないようにする必要がある |

## 案 B：追放テイマーの辺境牧場

> パーティーを追放された最弱テイマー。辺境で魔物を手なずけ、牧場で育てて、村を大きくしていく

| 項目 | 内容 |
| --- | --- |
| なろうの型 | 追放、テイマー、辺境スローライフ |
| 1 周 | 野原で魔物を弱らせて手なずける → 牧場に放す → 魔物が素材を生む（放置で貯まる）→ 素材で柵や小屋を建てて、もっと強い魔物が住めるようにする |
| 上位ゲームの要素 | 1（牧場が放置で稼ぐ）、3（レアな魔物がサーバー全体に出る時間）、4（レアな魔物を誰が先に手なずけるかの早い者勝ち）、5（色違い・大きさ違い、牧場を他の人に見せる） |
| 1 人で遊べるか | ◎ |
| 今の資産で使えるもの | モンスターと図鑑の考え方、クラフト、持ち物と保存、戦闘（弱らせる部分） |
| 小さく作るなら | 魔物 8 種、牧場の段階 3、建物 4 |
| 危ないところ | 育てる系は人気だが競争相手も多い。見た目の魅力（魔物の可愛さ）で勝負が決まりやすく、3D の素材が大量に必要 |

## 案 C：ダンジョンマスターの宝物庫

> 魔王軍を追い出された見習いダンジョンマスター。自分の迷宮を作って宝を貯め、他のマスターの宝物庫に忍び込む

| 項目 | 内容 |
| --- | --- |
| なろうの型 | ダンジョン経営、成り上がり |
| 1 周 | 自分の迷宮に罠と魔物を置く → NPC の冒険者が挑んで負けると宝が貯まる（放置）→ 他の人の迷宮に忍び込んで宝を盗む → 盗まれないように迷宮を強くする |
| 上位ゲームの要素 | 1、4（盗む・守る）、5（迷宮そのものが見せびらかし） |
| 1 人で遊べるか | △ NPC の冒険者で稼げるが、面白さの中心は他の人との盗み合い |
| 今の資産で使えるもの | 戦闘、持ち物と保存、モンスター |
| 小さく作るなら | 迷宮のマス 5×5、罠 4 種、魔物 4 種 |
| 危ないところ | **作る量が一番多い**（迷宮の組み立て画面、盗みの判定）。盗み合いは上位ゲームと型が近すぎるので、独自の味を出さないと埋もれる |

## 案 D：異世界食堂の成り上がり

> 生産職しか持たずに転生した料理人。森の素材を集めて新しい料理を作り、屋台を王都一の食堂にする

| 項目 | 内容 |
| --- | --- |
| なろうの型 | 生産職、料理、成り上がり |
| 1 周 | 森で素材を集める（弱い魔物と戦う）→ 組み合わせて料理を作る（新しいレシピを見つける）→ 店に並べると NPC の客が買っていく（放置）→ 稼ぎで店と道具を良くする |
| 上位ゲームの要素 | 1（店が放置で稼ぐ）、2（包丁・鍋を強くすると作れる料理が増える）、3（市場の珍しい素材が時間で入れ替わる）、5（料理の図鑑、店の飾り） |
| 1 人で遊べるか | ◎ |
| 今の資産で使えるもの | **レシピ・クラフト・素材のしくみ**、図鑑、持ち物と保存、戦闘（素材集めの部分） |
| 小さく作るなら | 素材 12、料理 10、店の段階 3 |
| 危ないところ | 対人の要素が弱く、他の人と遊ぶ理由が薄い。お酒を出す店にしない（18 歳以上限定になる） |

## 案 E：ステータス画面の塔

> 塔の 1 階で目覚めると、見えるのは自分のステータス画面だけ。登るほど能力の枠が増え、組み合わせで最強を目指す

| 項目 | 内容 |
| --- | --- |
| なろうの型 | ステータス画面、ハズレスキル、成り上がり |
| 1 周 | 階を登る（短いアクションと戦闘）→ 能力のかけらを拾う → 拠点の枠にはめる（パズルボックスの 3×3 がそのまま使える）→ 並びで「組み合わせ効果」が付く → もっと上へ |
| 上位ゲームの要素 | 2（枠が増えると行ける階が増える）、3（週替わりの階）、5（「到達階」と枠の見た目を頭上に出す） |
| 1 人で遊べるか | ◎ |
| 今の資産で使えるもの | **パズルボックス**、付与の上限コスト、戦闘、持ち物と保存 |
| 小さく作るなら | 10 階、かけら 12 種、枠 3×3 |
| 危ないところ | 放置で増える要素がなく、毎日来る理由が弱い。塔のステージ作りに手間がかかる |

## おすすめ

**A（ハズレスキル覚醒屋）**。上位ゲームの要素を 5 つ全部含められます。そのうえ、Phase 0 の「付与と解除」「上限コスト」「必殺技の種類の決まり方」がそのままゲームの中心に使えます。「ハズレのはずが実は強い」は、鑑定画面 1 枚で伝わります。言葉が分からない海外の子どもにも分かりやすい型です。

次点は **D（異世界食堂）**。いちばん安全で、毎日来る理由も作りやすい案です。ただ、他の人と遊ぶ理由をあとから足す必要があります。
